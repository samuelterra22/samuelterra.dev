O Telegram é o canal dos meus alertas: o Alertmanager avisa por lá quando um serviço cai. Este pacote leva o mesmo canal para dentro do Laravel, para notificações, mensagens avulsas e logs pela Bot API.

```bash
composer require samuelterra22/laravel-telegram-notifications
```

Versão atual: 0.4.0, de março de 2026. PHP 8.2, Laravel 11 e 12. Ainda antes da 1.0, então a interface pode mudar.
