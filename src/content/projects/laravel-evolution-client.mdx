A Evolution API é o servidor de WhatsApp que eu uso nos sistemas de clientes, do agendamento que confirma consulta até os alertas de operação. Este pacote embrulha a API numa interface Laravel, para a integração morar em um lugar só.

```bash
composer require samuelterra22/laravel-evolution-client
```

Versão atual: 1.0.2, de dezembro de 2025. PHP 8.1 a 8.4, Laravel 9 a 12.
